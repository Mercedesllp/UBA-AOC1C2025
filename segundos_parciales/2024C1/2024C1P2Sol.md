## Ejercicio 1
Agregar una syscall que le permita a la tarea que la llama espiar la memoria de las otras tareas en ejecución.

Copiar 4 bytes de una dirección de la tarea a espiar en una dirección de la tarea llamadora (tarea espía).

La syscall tiene los siguientes parámetros:

  - Selector de la tarea a espiar
  - vaddr a leer de la tarea espiada
  - vaddr a escribir de la tarea espía

Si la vaddr a espiar no esta mapeada en la tarea que corresponde l syscall devuelve '1 en eaxm si pudo devuelve 0.

### **a)**

Para que pueda ser invocado tengo que modificar lo siguiente:

La entry de la IDT con el número de la interrupción, es una interrupción de nivel 3:

``` C
// idt.c

void idt_init(){
  ...
  IDT_ENTRY3(100);
  ...
}
```

Tomo como convención que `eax` tiene el primer parámetro, `edi` el segundo y `esi` el tercero.
Luego defino la interrupción: 

``` asm
; isr.asm

; spy_task
_isr100:
  pushad
  push eax
  push edi
  push esi

  call spy_task

  add esp, 12

  ; Le pongo el resultado de si pudo o no espiar
  mov [esp + offset_EAX], eax   

  popad
  iret
```

## Ejercicio 2

Distingue tareas prioritarias de no prioritarias.

  - Prioritarias: Al saltar la int de reloj, tenga 0x00FAFAFA en `edx`.
  - No prioritarias: Las que no cumplan lo anterior o y/o pausadas y/o no ejecutables.

Cómo funciona:

  - Si no hay otra tarea prioritaria distinta se elige esa. Si hay mas de una se hace round-robin entre estas.
  - Si no, se elige normal.

Dónde se guarda el `edx` de nivel de usuario de las tareas desalojadas por el scheduler?

En la posición del stack0 a la que apunta el `esp0 + offset_EDX`. Esto es así debido a que en esta dirección está lo que se pusheó a la pila en la llamada del `isr32` y antes de hacer el `jmp far` se podrían haber modificado registros de la tarea interrumpida. La tss relacionada a esta tarea tinene los registros que modificó la `isr32`, o sea, los registros podrían no ser los mismos que cuando se interrumpió la tarea.

Cómo determina el scheduler que una tarea es prioritaria?

Con `edx`

``` C
// sched.c

uint16_t sched_next_task(void) {
  // Buscamos la próxima tarea viva (comenzando en la actual) y prioritaria
  int8_t i;
  for (i = (current_task + 1); i != MAX_TASKS + current_task + 1; i++) {
    // Si esta tarea está disponible la ejecutamos
    if (sched_tasks[i % MAX_TASKS].state == TASK_RUNNABLE) {
      break;
    }
  }

  // Ajustamos i para que esté entre 0 y MAX_TASKS-1
  i = i % MAX_TASKS;

  // Si la tarea que encontramos es ejecutable entonces vamos a correrla.
  if (sched_tasks[i].state == TASK_RUNNABLE) {
    current_task = i;
    return sched_tasks[i].selector;
  }

  // En el peor de los casos no hay ninguna tarea viva. Usemos la idle como
  // selector.
  return GDT_IDX_TASK_IDLE << 3;
}

```
