# Resolución Terminada
## Ejercicio 1
``` C
#define BUFFER_PHY 0xF151C000
#define BABA_VIRT 0xBABAB000
#define PD_TO_CR3(X) (X & 0xFFFFF000)
```


### **a)**
Para este punto tengo que tener en cuenta que la dirección física del buffer de video es `0xF151C000` y que la dirección de mapeo de DMA es `0xBABAB000`.

Entonces, básicamente lo que tendría que hacer es mapear la dirección física del buffer de video a la virtual dada.

``` C
void buffer_dma(pd_entry_t* pd){
  uint32_t cr3;

  // Obtengo el cr3 tomando la direccion base del pd (limpiando los últimos 12 bits)
  cr3 = PD_TO_CR3(pd);

  // No es writable debido a que solo lo puede escribir el lector de cartuchos
  mmu_map_page(cr3, BABA_VIRT, BUFFER_PHY, MMU_P | MMU_U);
}
```

### **b)**
Para este punto debería hacer una copia de la página física donde se encuentra el buffer de video `0xF151C000` en la dirección física `phys`.
Para esto puedo usar `copy_page()` y luego mapear `phys` en `0xBABAB000`.

``` C
buffer_copy(pd_entry_t* pd, paddr_t phys, vaddr_t virt){
  uint32_t cr3;
  // Copio el contenido del buffer en la otra dirección que me pasan por parámetro
  copy_page(phys, BUFFER_PHY);

  // Mapeo la dirección física a virt (que sería lo que esta en la dirección de ecx)
  cr3 = PD_TO_CR3(pd);
  // No es writable debido a que solo lo puede escribir el lector de cartuchos
  mmu_map_page(cr3, virt, phys, MMU_P | MMU_U);
}
```

## Ejercicio 2
Cada tarea tiene en `vaddr_t ACCE50` (mapeada r/w) un `uint8_t` con 0,1 ó 2.
- 0 = No accederá a video
- 1 = Accederá mediante DMA
- 2 = Accederá por copia -> Si este es el caso el dónde realizar la copia estará en `[ecx]` al momento de llamar `opendevice`

Cada vez que se complete el buffer (que se lo informa el lector al kernel mediante la IRQ 40) {se mapea este a las tareas que usen DMA/se actualiza la copia de los que usen copia} y solicitaron acceso al buffer.

Cada tarea que accede por copia mantiene una única copia del buffer.

Las tareas deben informar que quieren acceder al buffer mediante una syscall `opendevice`.

No se retoma la ejecución de las tareas que pidan el acceso del buffer hasta que el buffer esté listo y se haya hecho el mapeo de este.

Cuando la tarea deje de usar el buffer lo indica con `closedevice`.

Cosas previas a el punto a y b:
``` C
// mmu.c
#define ACCESO 0xACCE50

// Tipos de obtención de información del buffer que puede tener cada tarea
typedef enum {
  NO_ACCESS = 0,
  DMA = 1,
  COPY = 2
} access_t;

// Información de cada tarea que es necesaria para hacer la actualiación de la información del buffer
typedef struct{
  uint32_t cr3;
  access_t acceso;
  uint32_t ecx;
} entry_cartuchera_t;

// Array con las tareas que hayan dicho que quieren acceder al buffer
entry_cartuchera_t cartuchera[MAX_TASKS] = {0};
```

  ### **a)**
Debo agregar la entry de la interrupción 40 en la IDT (es nivel 0, pues es una interrupción externa)
``` C
// idt.c
void idt_init(){
  ...
  IDT_ENTRY0(40);
  ...
}
```
El código de la interrupción sería lo siguiente:
``` asm
; En isr.asm
_isr40:
  pushad  
  ; Aviso que se atendió la interrupción externa
  call pic_finish1

  ; Aviso que el buffer está ready a las tareas que le interese
  call deviceready

  popad
  iret
```

Tengo que avisarle a las tareas interesadas que el buffer esta ready y actualizar la info de los buffers de estas.
``` C
void deviceready(void){
  // Itero por todas las tareas interesadas en el buffer
  for(int i = 0; i < MAX_TASKS; i++){
    // Veo que haya un elemento en la entry
    if(cartuchera[i] != 0){
      // Veo que sea DMA el acceso
      if(cartuchera[i].acceso == DMA){
        buffer_dma((vaddr_t*)cartuchera[i].cr3);
      } 
      // Veo que sea por copia el acceso
      if(cartuchera[i].acceso == COPY){
        // Sé que la direccion física de la copia está en [ecx]
        vaddr_t virt = (vaddr_t)[cartuchera[i].ecx];

        // Obtengo la dirección física donde tenía la copia
        paddr_t phys = mmu_unmap_page(cartuchera[i].cr3, virt)

        // Copio el buffer donde corresponde
        buffer_copy((vaddr_t*)cartuchera[i].cr3, phys, virt);
      } 
      // Si es NO_ACCESS no hago nada
    }
  }
}
```

### **b)**

Declaro las entradas en la IDT de las syscalls (nivel 3, pues son interrupciones del sistema):

``` C
// idt.c
void idt_init(){
  ...
  IDT_ENTRY3(100);
  IDT_ENTRY3(101);
  ...
}
```

Definición de las interrupciones:

``` asm
; opendevice
_isr100:
  pushad
  
  // Pusheo el contenido de ecx como parámetro
  push ecx

  ; Acá voy a hacer lo principal, pasándole de parámetro ecx
  call opendevice

  add esp, 4
  popad
  iret

; closedevice
_isr101:
  pushad
  ; Acá voy a hacer lo principal
  call closedevice

  add esp, 12
  popad
  iret
  
```
Sé que en la variable `current_task` tengo el índice de la tarea que se estaba ejecutando cuando se llamó a `opendevice`.

En esta función necesitaría que se agregue a la lista de tareas a ser notificadas del completado del buffer.

Para esto, voy a obtener los parámetros necesarios del struct y luego meter el idx de la tarea en el mismo lugar que se encontraba en el `sched_tasks`.
``` C
void opendevice(uint32_t ecx){
  entry_cartuchera_t entry;
  uint8_t idx_task = current_task;

  // Ubico la tss de la task (se que el idx indicado en current task es el mismo para sched_tasks que para tss_tasks (por construcción en el tp)) y luego tomo el cr3 guardado en esta
  entry.cr3 = tss_tasks[idx_task].cr3;

  // Lo pushee antes de cualquier modificación para que me quede como parámetro de antes de llamar a la función
  entry.ecx = ecx;
  // Obtengo los 8 bits de la dirección que indica el tipo de acceso
  entry.acceso = (uint8_t)[0xACCE50]

  // Coloco toda la información en mi array donde tengo las tareas interesadas
  cartuchera[idx_tasks] = entry;
}
```

Luego, defino la función `closedevice` que lo que hace es sacar a la tarea de la cartuchera.

``` C
void closedevice(void){
  uint8_t idx_task = current_task;
  cartuchera[idx_tasks] = 0;
}
```
