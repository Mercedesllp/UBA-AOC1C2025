# Resolucion Terminada

## Ejercicio 1

Intercambio de registros de propósito general a nivel de usuario entre 2 tareas.

- La tarea de origen llama a swap con el id de la tarea con la que desea intercambiar registros.

- Si la tarea destino también llamó anterioprmente a swap con el id de la tarea origen, se realizará el intercambio de registos.

La syscalls deben intercambiar los registros sii la tarea a la que se le quiere intercambiar llamo a swap con esta tarea antes. Para saber esto necesito un registro de las tareas que llamen a swap con otras tareas.

Solo guardo el último swap que se quiso hacer.

``` C
// mmu.c

// Contiene el indice de la tarea con la que quiere swapear la tarea i
uint8_t tasks_swap[MAX_TASKS] = {-1};

// Funcion para intercambiar el contenido de dos elementos
void intercambiar(uint32_t* a, uint32_t* b){
  uint32_t temp = *a;
  *a = *b;
  *b = temp;
}
```

Pongo esto aca de reminder, pero esta en el TP también:

``` asm
%define offset_EAX 28
%define offset_ECX 24
%define offset_EDX 20
%define offset_EBX 16
%define offset_ESP 12
%define offset_EBP 8
%define offset_ESI 4
%define offset_EDI 0
```

### **a)**

Primero declaro la interrupción en la idt, esta está en nivel 3, porque es una syscall que solo necesita este privilegio.

``` C
void idt_init(){
  ...
  IDT_ENTRY3(100);
  ...
}
```

Defino la syscall swap de manera que llame a `swap()` y si no se pueden intercambiar se pausa la tarea hasta que se intercambien los registros.

``` asm
; swap
_isr100:
  pushad
  ; Asumo que el parámetro del idx de la otra task está siendo pasado por eax
  push eax
  call swap

  popad
  iret
```

Creo `swap()` de manera que modifique los registros o no dependiendo únicamente de si la otra tarea está queriendo swapear.

Para pausar y retomar las tareas uso `sched_disable_task` y `sched_enable_task`, usados en el TP.

``` C
// mmu.c

void swap(int8_t idx_task2){
  uint32_t* esp0_task1 = tss_tasks[idx_task1].esp0;

  // Guardo el índice de la tarea actual
  idx_task1 = current_task;

  // Inhabilito la task actual
  sched_disable_task(current_task);

  // Pongo a la otra tarea para que salte
  current_task = sched_next_task();

  // Si la tarea que se quiere swapear quiere también, intercambio los registros
  // Los de la actual estan pasados por parametro sus direcciones (por el pushad)
  // Los de la otra estan en su stack de nivel 0 por el pushad
  if(tasks_swap[idx_task2] == idx_task1){

    // Pongo en los registros generales de la tarea actual los valores de los registros de la otra tarea
    uint32_t* esp0_task2 = tss_tasks[idx_task2].esp0;

    intercambiar((uint32_t*)(esp0_task1 + offset_EAX), (uint32_t*)(esp0_task2 + offset_EAX));
    intercambiar((uint32_t*)(esp0_task1 + offset_ECX), (uint32_t*)(esp0_task2 + offset_ECX));
    intercambiar((uint32_t*)(esp0_task1 + offset_EDX), (uint32_t*)(esp0_task2 + offset_EDX));
    intercambiar((uint32_t*)(esp0_task1 + offset_EBX), (uint32_t*)(esp0_task2 + offset_EBX));
    intercambiar((uint32_t*)(esp0_task1 + offset_ESI), (uint32_t*)(esp0_task2 + offset_ESI));
    intercambiar((uint32_t*)(esp0_task1 + offset_EDI), (uint32_t*)(esp0_task2 + offset_EDI));

    // Habilito ambas tasks luego de intercambiar los registros
    // Si la segunda tarea no estaba inhabilitada para swapear esto no al afecta.
    sched_enable_task(idx_task1);
    sched_enable_task(idx_task2);

    // Voy a asumir que no se tienen que compartir indefinidamente, asi que la elimino de la tasks_swap
    tasks_swap[idx_task2] = -1;
  } else{
    // Pongo el idx de la task en tasks_swap
    tasks_swap[idx_task1] = idx_task2;
  }
}
```

Implemento `swap_now` a continuación:
Si la tarea que se quiere swapear quiere también (llamó a swap previamente la otra tarea), entonces hago el swap_now.

Puede ser que no se pueda swapear now si ambas tareas quieren hacerlo? Porque es medio, sucede ahora o no sucede mas.

Básicamente es lo mismo que antes, pero si lo hace, lo hace ahi no mas, y si no, no lo hace más, o sea, no se guarda el que haya querido swapear con alguna tarea.
