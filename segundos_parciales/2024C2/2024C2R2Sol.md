## Ejercicio 1

Intercambio de registros de propósito general a nivel de usuario entre 2 tareas.

- La tarea de origen llama a swap con el id de la tarea con la que desea intercambiar registros.

- Si la tarea destino también llamó anterioprmente a swap con el id de la tarea origen, se realizará el intercambio de registos.

La syscalls deben intercambiar los registros sii la tarea a la que se le quiere intercambiar llamo a swap con esta tarea antes. Para saber esto necesito un registro de las tareas que llamen a swap con otras tareas.

Solo guardo el último swap que se quiso hacer.

``` C
// mmu.c

typedef struct{
  uint8_t idx_task;
  uint32_t eax;
  uint32_t ecx;
  uint32_t edx;
  uint32_t ebx;
  uint32_t esi;
  uint32_t edi;

} entry_to_swap_t;

entry_to_swap_t tasks_swap[MAX_TASKS] = {0};
```

Defino la syscall swap de manera que llame a `swap()` y si esta devuelve `true` es que se pueden intercambiar, si no, es que se pausa la tarea hasta que se intercambien los registros.

Para pausar y retomar las tareas uso `sched_disable_task` y `sched_enable_task`, usados en el TP.

``` asm
; swap
_isr100:
  pushad
  push (esp + offset_EAX)
  push (esp + offset_ECX)
  push (esp + offset_EDX)
  push (esp + offset_EBX)
  push (esp + offset_ESI)
  push (esp + offset_EDI)
  ; Le paso las direcciones de la pila donde se encuentran los registros
  call swap

  popad
  iret
```

Creo `swap()` de manera que modifique los registros o no dependiendo únicamente de si la otra tarea está queriendo swapear.

``` C
// mmu.c

void swap(int8_t idx_task, uint32_t* eax, uint32_t* ecx, uint32_t* edx, uint32_t* ebx, uint32_t* esi, uint32_t* edi){
  
  // Inhabilito la task actual
  sched_disable_task(current_task);

  // Pongo a la task con los valores de sus registros en tasks_swap
  entry_to_swap_t entry = {.idx_task = idx_task, .eax = *eax, .ecx = *ecx, .edx = *edx, .ebx = *ebx, .esi = *esi, .edi = *edi};
  tasks_swap[current_task] = entry;

  // Si la tarea que se quiere swapear quiere también, intercambio los registros
  if(tasks_swap[idx_task] == current_task){
    *eax = tasks_swap[idx_task].eax;
    *ecx = tasks_swap[idx_task].ecx;
    *edx = tasks_swap[idx_task].edx;
    *ebx = tasks_swap[idx_task].ebx;
    *esi = tasks_swap[idx_task].esi;

    sched_enable_task(current_task);

    // Cuando yo le hago enable a esta task... Vuelve a ejecutarse la interrupción de swap? Si pasa, entonces se actualizan los valores ahi, si no, estoy al horno, no se que hacer :(
    sched_enable_task(idx_task);
  }
}
```
